# AnimalFarm

Плагин для расширенной фермерской механики Minecraft, **ориентированный на Purpur 26.2 и Java 26**.

## Платформа

AnimalFarm теперь собирается напрямую против **Purpur API**. Purpur наследует совместимость с Bukkit, Spigot, Paper и Pufferfish, но этот проект тестируется и предназначен для запуска именно на Purpur.

При запуске плагин проверяет ядро сервера. Если обнаружено не Purpur, AnimalFarm отключается с понятным сообщением в консоли.

## Основные системы

- кормушки и автоматические загоны;
- аквариумные кормушки и аквакультура;
- владельцы и доверенные игроки;
- автоматическое кормление и расход воды;
- расход корма 3–5 единиц в сутки по настройке;
- размножение животных и рыб с циклом 1–3 дня;
- золотой режим для ускоренного производства;
- молоко и индивидуальные ограничения по полу;
- шерсть и яйца;
- расширенный дроп;
- рыбалка и живой улов;
- выпуск свежей рыбы из инвентаря;
- забор рыб и разрешённых водных существ из аквариума;
- система пола коров, овец, коз, свиней и куриц;
- сохранение пола через `PersistentDataContainer`;
- HUD кормушек и HUD пола при наведении;
- русский конфиг и игровые сообщения.

## Система пола животных

Поддерживаются:

- 🐄 бык / корова;
- 🐑 баран / овца;
- 🐐 козёл / коза;
- 🐖 хряк / свинья;
- 🐔 петух / курица.

Пол назначается случайно, сохраняется непосредственно в сущности и не меняется после перезапуска сервера.

Размножение возможно только между взрослым самцом и взрослой самкой одного вида. Детёныш получает собственный пол сразу после рождения.

Для самцов коров и коз молоко отключено. Баран использует встроенный ванильный визуальный признак — чёрную шерсть.

## Кормушка

Кормушка создаётся из четырёх бочек:

```text
Бочка Бочка
Бочка Бочка
```

После установки она выглядит как обычная бочка и хранит данные AnimalFarm через `PersistentDataContainer`.

При наведении HUD может показывать количество животных, корм и воду.

## Аквариумная кормушка

Аквариумная кормушка создаётся из четырёх одинаковых рыб:

```text
Рыба Рыба
Рыба Рыба
```

Поддерживаются отдельные рецепты для:

- трески;
- лосося;
- тропической рыбы;
- иглобрюха.

Для аквариума HUD показывает количество рыб и запас корма.

## Аквариум и забор существ

Рыба забирается только при взаимодействии непосредственно с существом внутри зарегистрированного аквариума и с учётом владельца/доверия.

Обычная рыба возвращается соответствующим предметом. Разрешённые водные сущности, для которых нельзя выдать обычный предмет рыбы, возвращаются через яйцо призыва.

## Ресурс-пак

Ресурс-пак является **необязательным**. Purpur отправляет его игрокам через стандартный API, если включён раздел `resource-pack` в `config.yml`.

Текущая визуальная система **не использует ItemDisplay, PAPER, CustomModelData и подмену 3D-моделей**. Поэтому не создаёт фиолетово-чёрные квадраты и дополнительные сущности поверх животных.

Важно: обычный ванильный клиент не позволяет серверному плагину выбрать отдельную PNG-текстуру для конкретной коровы, козы, свиньи или курицы без дополнительного клиентского механизма вариантов текстур.

## Команды

- `/animalfarm reload` — перезагрузить конфигурацию;
- `/animalfarm info` — показать информацию о плагине;
- `/animalfarm trust <игрок>` — добавить доверенного игрока;
- `/animalfarm untrust <игрок>` — убрать доверенного игрока;
- `/animalfarm members` — показать участников;
- `/animalfarm owner` — показать владельца;
- `/animalfarm transfer <игрок>` — передать владение.

## Permission

- `animalfarm.admin` — административные команды.

## Сборка

Требуется Java 26:

```text
mvn clean package
```

Maven автоматически получает `purpur-api` из официального репозитория Purpur.

## Зависимости

AnimalFarm не требует обязательных сторонних плагинов. Основная серверная зависимость — **Purpur**.
