# AnimalFarm

Плагин для расширенной фермерской механики Minecraft.

## Основная идея

Плагин использует обычную ванильную бочку без изменения её внешнего вида. Четыре бочки крафтятся в специальную **Кормушку**.

Кормушка работает только как часть закрытого загона.

## Кормушка

Крафт:

```text
Бочка Бочка
Бочка Бочка
```

После установки кормушка выглядит как обычная бочка.

Внутрь можно положить корм:

- коровам — пшеницу;
- овцам/баранам — пшеницу;
- козам — пшеницу;
- курам — разрешённые семена.

### Вода

В кормушку можно добавить обычное **ведро воды** ПКМ.

После добавления:

- вода становится запасом воды кормушки;
- пустое ведро возвращается игроку;
- это же ведро можно снова наполнить и вернуть в кормушку.

## Автоматический загон

Для работы кормушки пространство должно быть закрыто.

Обязательные условия:

1. Кормушка находится внутри загона.
2. Граница загона сделана из заборов.
3. Загон полностью замкнут.
4. В загоне должна быть ровно одна **закрытая калитка**.
5. Внутри должен быть корм.
6. Внутри должна быть вода.
7. Для рождения детёныша нужны минимум два взрослых животных одного вида.

Если загон открыт или калиток нет/несколько, автоматическое размножение не работает. При взаимодействии с кормушкой игрок получает сообщение о причине.

## Размножение

Одиночное животное автоматически не размножается.

Примеры:

```text
1 корова + корм + вода = детёныш НЕ рождается
2 коровы + корм + вода = размножение
2 овцы + корм + вода = размножение
2 козы + корм + вода = размножение
2 курицы + семена + вода = размножение
```

Разные виды между собой не размножаются.

Автоматическая система использует стандартное состояние размножения Minecraft, поэтому детёныш появляется обычным способом.

## Доение

Если подойти к корове, овце/барану или козе с пустым ведром и нажать ПКМ, игрок получает ведро молока.

Для каждого животного настраивается задержка между доениями.

## Дроп

После смерти животных плагин добавляет настраиваемые предметы:

- корова — мясо, кожа, кости;
- овца/баран — мясо, кожа, шерсть, кости;
- коза — мясо, кожа, кости.

Количество каждого предмета задаётся в `config.yml`.

## Команды

- `/animalfarm reload` — перезагрузить конфигурацию.
- `/animalfarm info` — показать информацию о плагине.

## Permissions

- `animalfarm.admin` — административные команды.

## Локализация

Технические сообщения, описания, комментарии конфигурации и документация — на русском языке.

Команды и permissions — на английском языке.

## Зависимости

Плагин не требует отдельного ресурспака, ItemsAdder, Oraxen или других обязательных сторонних плагинов.
Используется стандартная ванильная бочка Minecraft.
