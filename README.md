# AnimalFarm

Плагин для расширенной фермерской механики Minecraft, работающий на совместимом **Bukkit/Spigot API**.

## Платформа

AnimalFarm не привязан к Purpur, Paper или другому конкретному ядру. Основная цель проекта — использовать совместимый Bukkit/Spigot API и запускаться на поддерживаемых серверных ядрах, реализующих этот API.

Требования:

- Java 26;
- сервер с совместимым Bukkit/Spigot API версии, соответствующей используемому `api-version`;
- Maven для сборки исходников.

Плагин не выполняет проверку конкретного ядра сервера и не отключается только из-за того, что сервер не является Purpur.

## Основные системы

- кормушки и автоматические загоны;
- анализ замкнутой области загона;
- аквариумные кормушки и аквакультура;
- владельцы и доверенные игроки;
- автоматическое кормление и расход воды;
- сохранение пустых вёдер после расходования воды;
- размножение животных и рыб;
- золотой режим ускорения;
- система пола животных;
- дойка только самок коров, овец и коз;
- шерсть и яйца;
- расширенный дроп;
- рыбалка и живой улов;
- выпуск живых существ;
- специальное ведро для переноса живых мобов с сохранением данных;
- HUD кормушек и HUD пола;
- русский конфиг и игровые сообщения.

## Система пола животных

Поддерживаются коровы, овцы, козы, свиньи, куры, лошади и кролики.

Пол хранится непосредственно в сущности через `PersistentDataContainer` и сохраняется после перезапуска сервера.

Для овец используется специальное визуальное правило:

- чёрная и тёмно-серая овца — баран;
- остальные цвета — овца.

Mooshroom не участвует в системе пола AnimalFarm и сохраняет ванильное поведение.

Размножение животных, использующих систему пола, возможно только между взрослыми самцом и самкой одного вида.

## Кормушка

Кормушка создаётся из четырёх бочек:

```text
Бочка Бочка
Бочка Бочка
```

Кормушка хранит данные AnimalFarm через `PersistentDataContainer`.

При расходовании `WATER_BUCKET` вода используется системой, а пустое `BUCKET` остаётся в кормушке.

## Аквариумная кормушка

Аквариумная кормушка создаётся из четырёх одинаковых рыб:

```text
Рыба Рыба
Рыба Рыба
```

Поддерживаются отдельные рецепты для трески, лосося, тропической рыбы и иглобрюха.

## Владение

Для объектов AnimalFarm поддерживаются:

- владелец;
- доверенные игроки;
- централизованная проверка доступа;
- передача владения;
- очистка старого списка доверенных игроков при передаче фермы.

## Команды

- `/animalfarm reload` — перезагрузить конфигурацию;
- `/animalfarm info` — показать информацию о плагине;
- `/animalfarm trust <игрок>` — добавить доверенного игрока;
- `/animalfarm untrust <игрок>` — убрать доверенного игрока;
- `/animalfarm members` — показать участников;
- `/animalfarm owner` — показать владельца;
- `/animalfarm transfer <игрок>` — передать владение.

## Permission

- `animalfarm.admin` — административные команды.

## Сборка

```text
mvn clean package
```

## Зависимости

AnimalFarm не требует обязательных сторонних плагинов и не зависит от конкретного серверного ядра.
