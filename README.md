# AnimalFarm

Плагин для расширенной фермерской механики Minecraft.

## Возможности

- Доение коров, овец/баранов и коз пустым ведром.
- Настраиваемый дроп мяса, кожи, шерсти и костей.
- Ванильный компостер работает как автоматическая кормушка.
- Пшеница автоматически кормит коров, овец и коз.
- Любые стандартные семена автоматически кормят кур.
- Автоматическое размножение животных с ограничениями по радиусу и количеству.
- Все пользовательские сообщения, описания и комментарии на русском языке.
- Команды и permissions остаются на английском языке для совместимости.

## Команды

- `/animalfarm reload` — перезагрузить конфигурацию.
- `/animalfarm info` — показать информацию о плагине.

## Permissions

- `animalfarm.admin` — административные команды.

## Важно

Плагин не требует отдельного ресурспака и использует стандартные блоки и предметы Minecraft.
